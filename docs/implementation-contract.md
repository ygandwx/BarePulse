# Implementation contract (2026-10-15)

Module: `github.com/ygandwx/BarePulse`, Go 1.27.2, PostgreSQL 18.6, modular monolith. Same-origin HTML + ES modules, no frontend dependency chain. IDs are random hex text; timestamps UTC, JSON snake_case. Currency/enforcement policies disabled.

Shared Go package `backend/internal/app`: `App{DB *pgxpool.Pool, Config Config}`, `User{ID,Email,Role string}`. Register modules with `registerInventory`, `registerOperations`, `registerTraffic`, `registerConsole`, `registerWHMCS`. Each takes no arguments and adds routes through `a.route(pattern string, admin bool, func(http.ResponseWriter,*http.Request,User) error)`. `a.Mux` is *http.ServeMux. Helpers: `decode(r,&body) error` rejects unknown fields; `jsonResponse(w,status,value)`; `fail(status,code,message) error`; `newID() string`; `audit(ctx,tx pgx.Tx,u User,action,object string,details any) error`; `dbError(err) error`; `a.server(ctx,id,u) (Server,error)` enforces owner; `a.RunWorker(ctx)` owned by operations module. No user-supplied device URLs/ports in customer actions. Successful JSON objects directly, lists as JSON arrays. Errors `{error:{code,message},request_id}`.

Base schema 001 is owned by main. `users(id,email,password_hash,role,created_at)` roles admin/customer/operator (operator read-only unless expressly granted). `servers(id,name,owner_id,model,notes,maintenance,version,created_at,updated_at)`; `devices(id,name,kind,address,credential_ref,scenario,enabled,version,lease_owner,lease_kind,blocked_reason,cooldown_until,created_at,updated_at)`; kinds mock_pikvm/mock_pdu/mock_bmc/pikvm/apc/redfish/ipmi/snmp; simulated scenarios success/offline/inner_error/timeout/busy. `bindings(id,server_id,device_id,kind,port,version,active,created_at,ended_at)` kinds power/console/network, integer ports. Historical binding preserved. `operation_tasks(id,actor_id,server_id,device_id,binding_id,binding_version,server_version,action,idempotency_key,status,result,created_at,updated_at)`; result jsonb. `audit_events(id,actor_id,action,object_id,details,created_at)`. No secrets in audit or responses. Persistent device lease shared by power and console, never expire/reassign unknown executor automatically.

Ownership for initial parallel work:
- Foundation agent: `inventory.go`, `operations.go`, corresponding `_test.go`, frontend `inventory.js`/`operations.js`, `docs/modules/foundation.md`. No edits to app.go/auth.go/base schema/go.mod. Implement CRUD and historical/version binding updates, durable power queue and mocks integration. Route paths: /api/v1/servers, /api/v1/devices, /api/v1/bindings, /api/v1/users, /api/v1/tasks, /api/v1/audit, /api/v1/servers/{id}/power, /api/v1/servers/{id}/power-actions. Admin mutation paths same. App invokes `RunWorker`. Use drivers.Mock Execute contract below; real drivers remain disabled unless integrated deliberately.
- Traffic agent: `traffic*.go`, `002_traffic.sql`, `frontend/traffic.js`, `docs/modules/traffic.md`. Complete accounting + API/UI/tests, independent tables reference base. Constructor/register `registerTraffic()`. Export helper integration only by messages. No global module edits. Source ownership immutable + history; explicit overlap domains reject port/VLAN overlap across accounts.
- Driver agent: `backend/internal/drivers/**`, `docs/modules/drivers.md`; no app changes. Define `Target{DeviceID,Kind,Address,Username,Password,Scenario string; Port int}`; `Result{Status,Code,Message,PowerState,SupplyState string; Accepted,Completed,TargetReached bool; CooldownSeconds int}` JSON snake_case; `Driver` interface Execute(ctx,Target,action) Result. `NewMock() *Mock`; stateful/mock faults. Implement evidence-backed PiKVM HTTP, configurable APC SNMP profile with no guessed OIDs, capability-driven Redfish/IPMI where feasible, strict no-network defaults, loopback contract tests. Do not change go.mod; tell main necessary dependencies.
- Main: foundation app/auth/migrations, console, integrations, frontend shell, runtime setup/CI/deployment, integrated tests, progress and commits.

Frontend ES modules export `mount(root,api,user)`; api(path, options) returns parsed JSON or throws Error with code; paths include /api/v1. UI DOM textContent, avoid untrusted innerHTML. Shell nav mounts modules; each module handles forms/list updates and visible errors. Frontend assets embedded by separate frontend Go package. No build required.

Tests: `TEST_DATABASE_URL` enables real PostgreSQL tests; no false PASS when unavailable. Main provides `testApp(t)` helper in `app_test.go` returning *App with isolated schema + authenticated request helpers. Do not depend on helper until shared definition delivered; use own pg integration where needed. Never connect real devices. Report actual executed commands and failures to main; do not commit concurrently.
